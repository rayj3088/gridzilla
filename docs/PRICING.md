# Pricing

## Open core: free

The map, the simulator, every layer, the source registry, site ranking and
reports. Apache 2.0, so anyone can self-host it, fork it or use it
commercially. This is the standard-setter: it should be the map people cite.

## API license: $25,000 per year

For teams that want the engine inside their own tools instead of a browser tab:

- Programmatic access to the simulation engine (scenario scoring, headroom,
  site ranking).
- Batch scoring: up to 500 sites (by state) in one call.
- Priority data refresh, once a licensed pipeline feed is funded (see below).

Why the app is free and the API is not: anyone can rebuild a map, and a map
you have to log into never becomes the standard. Headroom itself still runs
on the same static 2025 study as the free app — both now also carry real,
current interconnection-queue capacity (LBNL's free "Queued Up" dataset),
but free tools like
[Interconnection.fyi](https://www.interconnection.fyi/) already track more
live grid data than either of ours does. The $25,000 is what funds closing
the rest of that gap: a licensed pipeline feed for headroom itself,
integrated here first. Until that happens, buy this for the stable
interface and batch scoring, not for data you can't already get for free.
